# 100 Days of DevOps

This repository documents my journey through KodeKloud's 100 Days of DevOps challenge. It contains notes, solutions, and step-by-step explanations for various DevOps tasks and concepts.

## Purpose

The goal of this repo is to:

- track daily learning progress
- document practical DevOps tasks
- build a personal reference for commands and solutions
- strengthen Linux, system administration, and automation skills

## Repository Structure

- Day 1 - Linux User Setup with Non-Interactive Shell
  - Contains the task description and a step-by-step solution for creating a user with a non-interactive shell on a Linux server

## How to Use This Repo

1. Open any day file to review the task.
2. Follow the solution steps and commands.
3. Use the notes as a reference for future practice.

## Topics Covered

This learning path focuses on core DevOps fundamentals such as:

- Linux administration
- User and permissions management
- Shell scripting
- System troubleshooting
- Server setup and configuration

## Note

This repository is a personal learning record and is inspired by KodeKloud's 100 Days of DevOps program.
